# Управление на служебни абонаменти (Micro-SaaS)

Пълнофункционално уеб приложение за проследяване на 12-месечни абонаментни договори и регулярността на плащанията по тях. Всички текстове са на български език.

## Технологичен стек

- **Next.js 14** (App Router) с TypeScript
- **Tailwind CSS** + Lucide React + shadcn/ui компоненти
- **Supabase** (PostgreSQL) – база данни и автентикация
- **date-fns** – форматиране на дати

## Структура на проекта

```
supabase/
  schema.sql      # SQL схема с таблици, тригери и RLS политики
  seed.sql        # 10 демо договора за тестване
src/
  app/
    page.tsx      # Главно табло (Dashboard)
    layout.tsx    # Корен layout
    globals.css   # Стилове
  components/
    ui/           # shadcn/ui базови компоненти
    contracts/    # Таблица, модали, панел за история
    shared/       # Светофарни статусове, форматиране
  lib/
    supabase.ts   # Supabase клиент
    contracts.ts  # Бизнес логика
  types/
    database.ts   # TypeScript типове
.env.local.example
```

## Инсталиране и стартиране

### 1. Инсталиране на зависимости

```bash
cd d:\slujeben-abonament-saas
npm install
```

### 2. Supabase конфигурация

Копирайте `.env.local.example` в `.env.local` и попълнете стойностите:

```bash
cp .env.local.example .env.local
```

Редактирайте `.env.local`:

```env
NEXT_PUBLIC_SUPABASE_URL=ваш supabase URL
NEXT_PUBLIC_SUPABASE_ANON_KEY=ваш anon ключ
```

### 3. Инициализиране на базата данни

В Supabase Dashboard, отидете на **SQL Editor** и изпълнете следните файлове по ред:

1. `supabase/schema.sql` – създава таблици, тригери, индекси и RLS политики
2. `supabase/seed.sql` – добавя 10 демо договора за тестване

### 4. Старт на desenvolvimento сървъра

```bash
npm run dev
```

Приложението ще бъде достъпно на `http://localhost:3000`.

## Функционалност

### Главно табло (Dashboard)

- 4 KPI картки: Общо активни, Просрочени, Предстоящи (15 дни), Изтичащи договори
- Търсачка по клиент, рег. номер или номер на договор
- Табове: Всички активни | Просрочени | Предстоящи | Изтичащи | Архив
- Таблица сортирана по спешност (първо просрочените)

### Светофарна система

| Цвят | Статус на плащане | Статус на договор |
|------|------------------|-------------------|
| 🔴 Червен | Просрочен | Изтекъл договор |
| 🟡 Жълт | Предстои плащане (≤ 15 дни) | Изтича скоро (≤ 30 дни) |
| 🟢 Зелен | Редовен | Активен договор |
| 💎 Дългосрочно | Платени изцяло | — |

### Бързи действия

- **€ Плащане** – записване на ново плащане с бързи бутони (1, 2, 3, 6 месеца, до края на договора)
- **История** – преглед на всички плащания по договора с възможност за изтриване
- **Подновяване** – създаване на нов 12-месечен договор при изтичане

## Качване в Vercel

1. Изградете проекта в GitHub хранилище
2. Отидете на [Vercel](https://vercel.com) и импортирайте хранилището
3. Добавете променливи на околна среда:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
4. Натиснете **Deploy**

## Seed данни

Файлът `supabase/seed.sql` съдържа 10 договора pokrivajući всички сценарии:
- 2 договора платени напред за 12 месеца (💎 Платен изцяло)
- 2 просрочени договора (🔴 Просрочен)
- 2 договора с предстоящо плащане до 10 дни (🟡 Предстои плащане)
- 1 договор с изтичащ 12-месечен срок (⏳ Изтича скоро)
- 1 архивиран изтекъл договор (⛔ Изтекъл договор)
